# homebrew-epicli

Homebrew tap for [epicli](https://github.com/mainstreamer/config) — shell environment manager.

## Install

```bash
brew tap mainstreamer/epicli
brew install epicli
```

## Usage

```bash
epicli          # Run full setup (deps, symlinks, configs)
epicli help     # Show available commands
epicli status   # Check current installation
epicli update   # Update to latest version
```

## Alternative install

```bash
curl -fsSL https://tldr.icu/i | bash
```
